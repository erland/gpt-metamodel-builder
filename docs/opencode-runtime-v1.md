# OpenCode runtime v1

OpenCode-distributionen är Metamodel Builders mest exekverbara runtime. Den innehåller canonical instruktioner, schemas, Python-validatorer/generatorer, mallar, referensexempel och stateful workspace.

## OpenCode-integration

- `AGENTS.md` ger repo-wide instruktioner.
- `.opencode/agents/metamodel-builder.md` definierar en primär Metamodel Builder-agent.
- `.opencode/skills/metamodel-validation/SKILL.md` beskriver valideringskedjan.
- `.opencode/skills/sparx-mdg/SKILL.md` beskriver Sparx MDG-flödet.
- `opencode.jsonc` väljer Metamodel Builder som standardagent.
