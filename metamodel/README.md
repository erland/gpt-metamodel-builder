# Canonical metamodel

Den här katalogen beskriver canonical representationen. Ett aktivt användarprojekt ska innehålla de sju YAML-filerna som definieras i `docs/canonical-metamodel-v1.md`.

- Mallar: `templates/metamodel/`
- Referensmodell: `examples/architecture-lite/`
- JSON Schemas: `schemas/*schema.json`

Canonical YAML är sanningskällan.
